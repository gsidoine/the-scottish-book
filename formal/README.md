# Formal verification

Pinned Lean projects are maintained in [formal/ArithmeticGraphs](ArithmeticGraphs/README.md) and [formal/P010](P010/README.md). Problem dossiers link to these certificates; specialized problem folders may also have a `formal/` subdirectory when warranted. No empty `Pxxx.lean` placeholder is presented as a formal proof.

A repository statement is *Lean-verified* only when its exact declaration passes the pinned build. A formalized **statement** without a verified **solution** must be labeled accordingly. Informal mathematical proof, finite computation, Lean verification and historical novelty are separate assessments.
